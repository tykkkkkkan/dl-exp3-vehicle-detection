# 深度学习基础及应用 · 实验3：车辆目标检测

基于 PyTorch 的简化版 YOLOv8 目标检测器，在 PASCAL VOC2007 上检测 **car / bus** 两类车辆。本仓库包含完整可运行代码、真实训练日志与检测可视化。

## 任务

输入一张自然图像，输出图中所有车辆的位置（边界框）与类别，并按 mAP@0.5 评价。

## 数据与预处理

- 数据集：PASCAL VOC2007（官方 trainval，5011 张）
- 类别：`car`、`bus`；筛选含至少一个车辆目标的图像
- 规模：训练 **459** 张 / 验证 **410** 张，平均每图 **2.2** 个目标
- 标注解析：XML → 归一化 `[x1,y1,x2,y2]`
- 目标编码：7×7 网格，每格 `[obj, cls_onehot, tx, ty, tw, th]`
- 数据增强：水平翻转（同步变换框）、亮度扰动、±10° 随机旋转；每图生成 2 个增强版本

## 模型

**预训练骨干 + YOLOv8 风格解耦头**：

| 模块 | 结构 | 参数量 |
|---|---|---|
| 骨干（冻结） | ResNet18（ImageNet 预训练），取 layer4 → 7×7×512 | 11,176,512 |
| 检测头（可训练） | 1×1 精炼 512→64 + BN + ReLU，解耦出 obj / cls / box 三支 | 33,351 |
| **总计** | | **11,209,863** |

设计说明：小数据集（数百张）在 CPU 上从零训练特征提取器会严重欠拟合，因此采用迁移学习并冻结骨干；冻结后特征可预先缓存，检测头训练成本极低（400 轮仅约 8 分钟 CPU）。

## 完整流水线

`XML 标注解析 → 数据增强 → 冻结骨干提取并缓存特征 → 训练检测头 → NMS 后处理 → mAP@0.5 评测`

## 真实结果

| 指标 | 数值 |
|---|---|
| **mAP@0.5** | **0.0738** |
| AP(car) | 0.0424 |
| AP(bus) | 0.1053 |
| 训练轮数 | 400（batch=32，Adam，lr=1e-2，余弦退火） |
| 训练耗时 | 8.21 分钟（CPU） |
| 最优子集 mAP | 0.1059（按验证 mAP 保存最优权重） |

### 关键工程问题：正负样本不平衡

7×7=49 个格点中通常仅 1~2 个含目标（正负比约 1:24）。直接使用普通 BCE 会让背景格点梯度压倒目标格点，模型退化为"全预测无目标"——训练损失很低，但 mAP 趋近 0（实测仅 0.007）。本实现用 `pos_weight = 负样本数 / 正样本数` 动态加权，使正负梯度量级对等，mAP 提升约 **10 倍**。

坐标回归使用 Smooth-L1（β=0.1），总损失 `obj + 10 × box + cls`。

### 结果分析

- 模型已能对占比较大、轮廓清晰的车辆给出位置基本正确的框（见 `outputs/exp3_vis_grid.png`），但仍存在框偏大、背景误检与漏检。
- **bus 的 AP 显著高于 car**（0.105 vs 0.042）：公交车体积大、外观统一；小轿车尺度跨度大、遮挡多，且单格点只预测一个框，密集场景必然漏检。
- mAP 计算已用"完美预测"做单元测试：完全命中返回 1.0、全错返回 0.0、半对返回 0.5，确认评测无误。

## 改进方向

1. **多尺度 + 多框**：引入 FPN（P3/P4/P5）与多锚框，解决密集/小目标漏检
2. **解冻骨干微调**：当前骨干完全冻结，ImageNet 特征与车辆域仍有差距
3. **扩充数据**：VOC2012 / COCO，配合 Mosaic、MixUp 等强增强
4. **更优正样本分配**：用 YOLOv8 的 Task-Aligned Assigner 替代"中心落格"硬分配
5. **GPU 训练**：可支持更高分辨率、更大模型与更长训练
